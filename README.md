# أبو مهند البطران — تطبيق الصف التاسع

مشروع Flutter أولي باللغة العربية وباتجاه من اليمين إلى اليسار، يحتوي حالياً على:
- شاشة رئيسية باسم «أبو مهند البطران».
- شاشة تعرض مواد الصف التاسع.
- صفحة مبدئية لكل مادة لاستقبال فهرس الكتاب والدروس.
- إعدادات ألوان ومسارات وهيكل ملفات قابل للتوسّع.

## التشغيل
1. ثبّت Flutter وAndroid Studio أو VS Code.
2. افتح الطرفية داخل مجلد `smart_ninth`.
3. نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```
